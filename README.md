## 📌 Description

Ce dépôt contient un ensemble complet de **codes sources en Python pour la programmation graphique (GUI)**, développé dans le cadre du cours de **Master 1 – Systèmes Réseaux et Télécommunications (SRIT)**.

🎯 Objectif :
- Apprendre à créer des interfaces graphiques modernes
- Développer des applications professionnelles
- Intégrer des bases de données
- Implémenter des systèmes sécurisés (Login + OTP)
- Réaliser des projets concrets (gestion, pharmacie, POS, dashboard)

### 🧩 Module 3 : Design moderne
- Couleurs professionnelles
- Icônes et images
- Sidebar & Dashboard

### 🧩 Module 4 : Base de données
- SQLite / MySQL
- CRUD complet
- Intégration avec interface

### 🧩 Module 5 : Login sécurisé

- Rôles (Admin / Agent)
- Sessions

- Gestion étudiants
